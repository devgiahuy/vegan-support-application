# Vegan Support Application — Frontend (Next.js 16)

Ứng dụng hỗ trợ người ăn chay: tìm công thức theo nguyên liệu, hỏi AI dinh dưỡng,
lên thực đơn tuần, tìm quán chay lân cận, chia sẻ blog/video + bình luận/vote.
Admin duyệt bài, quản category/user.

```
Tìm công thức -> Chi tiết + gợi ý -> Hỏi AI -> Meal Plan
-> Tìm quán (Map) -> Đăng Blog/Video + Comment/Vote
```
